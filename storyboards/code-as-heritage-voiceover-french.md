Transcription

Avant même que le génie logiciel ne porte ce nom, c’était un travail de femmes. Aux débuts de l’informatique, la programmation était largement considérée comme un travail de bureau — précis, minutieux, et donc confié aux femmes. Les six femmes qui ont programmé l’ENIAC, l’un des premiers ordinateurs électroniques, ont mis au point des techniques fondamentales avant même que la discipline ne dispose d’un vocabulaire propre. Pendant des décennies, leurs noms ont été systématiquement exclus des archives historiques.

Pourtant, leur code a survécu. Étudié par les historiens aux côtés d’archives et de témoignages, il devient une source permettant de révéler les histoires humaines qui se cachent derrière la technologie.

Le code, c’est ce qui permet aux machines d’exécuter des tâches. Les machines ont leur propre langage, mais nous l’utilisons rarement. Les langages de programmation, traduits par d’autres programmes, nous protègent du fonctionnement interne de la machine. C’est ce qu’on appelle l’abstraction : libérés de ces détails, nous nous concentrons sur notre problème, et le code devient plus facile à écrire et moins sujet aux erreurs.

En 1969, Margaret Hamilton a dirigé l’équipe du MIT chargée d’écrire le logiciel de l’Apollo Guidance Computer — le programme qui a guidé Apollo 11 jusqu’à la Lune. Elle a inventé le terme « génie logiciel » pour conférer à cette discipline un statut professionnel. Les piles de code imprimé à côté d’elle sur cette photo atteignent à peu près sa taille.

Mais comment s’est-elle passée l’écriture de ce code ?

*Extraits d’une interview de Margaret Hamilton*

« Il n’y avait que des hommes. Que des hommes et moi. »

« Il m’a dit : “Comment pouvez-vous travailler ici alors que vous avez un bébé à la maison ?” »

« Les ingénieurs trouvaient ça drôle… “Voilà encore Margaret, avec son ingénierie logicielle.” »

« J’ai découvert que certains hommes gagnaient deux fois plus que les femmes, sans aucune raison. »

Rien de tout cela n’apparaît directement dans le code. Pour le mettre au jour et faire ressortir la dimension de genre, les historiens ont dû croiser l’artefact technique avec des témoignages oraux.

Parfois, un petit détail dans le code peut révéler une histoire plus vaste. Dans le logiciel du module lunaire Apollo, une routine porte un nom inattendu : BURN_BABY_BURN. Pris isolément, ce code n’est qu’une simple étiquette.
Mais lorsque les historiens ont interrogé l’un de ses auteurs, ils ont découvert les références culturelles qui se cachaient derrière : une expression popularisée par le DJ de radio de Los Angeles Magnificent Montague dans les années 1960, associée par la suite aux émeutes de Watts de 1965.

Le code nous invite à interroger le contexte technique, social et culturel dans lequel il a été produit. Il s’agit là de recherche historique en pratique : interpréter le code source à la lumière de témoignages, d’archives et d’autres éléments historiques.

Mais avant que les historiens puissent étudier le code, celui-ci doit avoir survécu. Les logiciels des années 1960 ont rarement résisté aux restructurations d’entreprises, aux évolutions technologiques ou à la simple négligence — et le code source, contrairement aux programmes exécutables, était particulièrement vulnérable.

Les listes du programme Apollo ont survécu parce que des copies papier ont été conservées au musée du MIT, et parce que des personnes dévouées ont par la suite entrepris le travail de numérisation et de transcription.

Des cartes perforées aux listes sur papier, des images numérisées aux fichiers texte et au dépôt GitHub, le code a trouvé une nouvelle vie numérique.

Ce processus peut être considéré comme une « renaissance numérique » : un logiciel récupéré à partir de supports physiques conservés et reconstitué sous forme numérique.

Au cours de son parcours, ce code est passé par trois des principales institutions qui se consacrent aujourd’hui à la préservation du patrimoine logiciel. Le programme d’archivage GitHub stocke le code dans une chambre forte située dans l’Arctique, conçue pour durer des siècles. Au-delà du code, Internet Archive rend de nombreux programmes historiques accessibles grâce à une émulation via navigateur. Software Heritage, une association universitaire française à but non lucratif, a pour objectif de préserver l’ensemble du code source accessible au public.

Chaque couche de code qui a construit notre monde numérique est porteuse de décisions, d’hypothèses et de vies. Apprendre à le lire d’un point de vue historique, c’est apprendre à se demander non seulement ce qu’il fait, mais aussi qui l’a écrit, dans quelles conditions, et quelles autres sources sont nécessaires pour le comprendre pleinement. Ce cours vous montrera comment y parvenir.
