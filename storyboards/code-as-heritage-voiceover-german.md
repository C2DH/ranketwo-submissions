Bevor die Softwareentwicklung einen Namen hatte, war sie Frauenarbeit. In den Anfängen der Informatik galt das Programmieren weitgehend als Büroarbeit – präzise, mühsam und daher Frauen vorbehalten. Die sechs Frauen, die den ENIAC, einen der ersten elektronischen Computer, programmierten, entwickelten grundlegende Techniken, noch bevor es für dieses Fachgebiet überhaupt einen Begriff gab. Jahrzehntelang wurden ihre Namen systematisch aus den historischen Aufzeichnungen ausgeklammert.

Doch ihr Code hat überdauert. Von Historikern anhand von Archiven und Zeitzeugenberichten untersucht, wird er zu einer Quelle, die die menschlichen Geschichten hinter der Technologie offenbart.


Code ist die Art und Weise, wie wir Maschinen dazu bringen, Aufgaben auszuführen. Maschinen haben ihre eigene Sprache, aber wir schreiben selten darin. Programmiersprachen, die von anderen Programmen übersetzt werden, schirmen uns von den inneren Abläufen der Maschine ab. Das ist AbstraktionBefreit von diesen Details konzentrieren wir uns auf unser Problem, und Code lässt sich leichter schreiben und ist weniger fehleranfällig.

1969 leitete Margaret Hamilton das Team am MIT, das die Software für den Apollo Guidance Computer schrieb – das Programm, das Apollo 11 zum Mond navigierte. Sie prägte den Begriff ‚Software Engineering‘, um der Disziplin einen professionellen

Status zu verleihen. Die Stapel gedruckten Codes neben ihr auf diesem Foto sind etwa so hoch wie sie selbst.

ErzählerAber wie war es, sie zu schreiben?

Erzähler (oder direkter Audioausschnitt, noch zu bestätigen):

„Es waren alles Männer. Nur Männer und ich.“

„Er sagte‚Wie kannst du hier arbeiten, wenn du zu Hause ein Baby hast?‘“

„Die Ingenieure fanden das lustig. Da ist wieder Margaret mit ihrer Softwareentwicklung.“
„Ich fand heraus, dass manche Männer ohne jeden Grund doppelt so viel verdienten wie Frauen.“

ErzählerNichts davon geht direkt aus dem Code hervor. Um dies aufzudecken und die geschlechtsspezifische Dimension sichtbar zu machen, mussten Historiker die technischen Artefakte mit mündlichen Aussagen verknüpfen.

ErzählerManchmal kann ein kleines Detail im Code eine größere Geschichte offenbaren. In der Software der Apollo-Mondlandefähre trägt eine Routine einen unerwarteten NamenBURN_BABY_BURN. Für sich genommen ist dieser Code nur eine Bezeichnung.
Als Historiker jedoch einen der Autoren befragten, deckten sie die kulturellen Bezüge dahinter aufeinen Ausdruck, der in den 1960er Jahren durch den Radio-DJ Magnificent Montague aus Los Angeles populär wurde und später mit den Watts-Unruhen von 1965 in Verbindung gebracht wurde.

Code lädt uns dazu ein, den technischen, sozialen und kulturellen Kontext seiner Entstehung zu hinterfragen. Das ist historische Forschung in der PraxisQuellcode im Lichte von Zeugenaussagen, Archiven und weiteren historischen Belegen zu interpretieren.

Doch bevor Historiker Code untersuchen können, muss er erst einmal erhalten bleiben. Software aus den 1960er Jahren überstand Unternehmensumstrukturierungen, technologischen Wandel oder schlichtweg Vernachlässigung nur selten – und Quellcode war, im Gegensatz zu ausführbaren Programmen, besonders gefährdet.

Die Apollo-Listings blieben erhalten, weil Papierkopien im MIT Museum landeten und weil engagierte Personen später die mühsame Arbeit der Digitalisierung und Transkription auf sich nahmen.
Von Lochkarten über Papierlistings, von gescannten Bildern bis hin zu Textdateien und einem GitHub-Repository – der Code erhielt ein neues digitales Leben.

Dieser Prozess lässt sich als ‚digitale Wiedergeburt‘ verstehenSoftware, die aus erhaltenen physischen Aufzeichnungen wiederhergestellt und in digitaler Form rekonstruiert wurde.

Auf seiner Reise durchlief dieser Code drei der wichtigsten Institutionen, die sich heute der Bewahrung des Software-Erbes widmen. Das GitHub Archive Program speichert Code in einem arktischen Tresorraum, der für eine Lebensdauer von Jahrhunderten ausgelegt ist. Über den Code hinaus macht das Internet Archive viele historische Programme durch browserbasierte Emulation zugänglich. Software Heritage, eine französische akademische gemeinnützige Organisation, hat sich zum Ziel gesetzt, den gesamten öffentlich zugänglichen Quellcode zu bewahren.

Jede Codeebene, aus der unsere digitale Welt besteht, birgt Entscheidungen, Annahmen und Lebensgeschichten. Sie historisch zu lesen bedeutet, nicht nur zu fragen, was der Code tut, sondern auch, wer ihn geschrieben hat, unter welchen Bedingungen und welche weiteren Quellen erforderlich sind, um ihn vollständig zu verstehen. In dieser Lektion erfahren Sie, wie das geht.
