Softwareentwicklung war Frauenarbeit, lang bevor ein Begriff für diese Tätigkeit aufkam. In den Anfängen der Informatik galt Programmieren weitgehend als Büroarbeit – präzise, mühsam und daher Frauen vorbehalten. Die sechs Frauen, die einen der ersten elektronischen Computer, den ENIAC, programmierten, entwickelten grundlegende Techniken, noch bevor sich überhaupt ein fachspezifisches Vokabular etablierte. Jahrzehntelang wurden ihre Namen systematisch aus den historischen Aufzeichnungen ausgeklammert.

Doch ihr Code hat überdauert. Historikerinnen und Historiker untersuchen ihn als Quelle, die zusammen  mit Archivmaterialien und Zeitzeugenberichten die menschlichen Geschichten hinter der Technik sichtbar macht.

Mit Code  bringen wir Maschinen dazu, Aufgaben für uns auszuführen. Maschinen haben ihre eigene Sprache, aber wir schreiben selten darin. Programmiersprachen, die von anderen Programmen übersetzt werden, schirmen uns von den inneren Abläufen der Maschine ab. Das ist eine Form der Abstraktion: Befreit von diesen Details konzentrieren wir uns auf unser Problem, Code lässt sich leichter schreiben und ist weniger fehleranfällig.

1969 leitete Margaret Hamilton das Team am MIT, das die Software für den Apollo Guidance Computer schrieb – das Programm, das Apollo 11 zum Mond navigierte. Sie prägte den Begriff ‚Software Engineering‘, um dem Fach ein professionelles Ansehenzu verleihen. Die Stapel gedruckten Codes neben ihr auf diesem Foto sind etwa so hoch wie sie selbst.

Erzähler: Aber wie war es, sie zu schreiben?

Erzähler (oder direkter Audioausschnitt, noch zu bestätigen):
„Es waren alles Männer. Nur Männer und ich.“

„Er sagte‚ wie kannst du hier arbeiten, wenn du zu Hause ein Baby hast?‘“

„Die Ingenieure fanden das lustig. Da ist wieder Margaret mit ihrer Softwareentwicklung.“

„Ich fand heraus, dass manche Männer ohne jeden Grund doppelt so viel verdienten wie Frauen.“

Erzähler: Nichts davon geht direkt aus dem Code hervor. Um dies aufzudecken und die geschlechtsspezifische Dimension sichtbar zu machen, mussten Historiker die technischen Artefakte mit Augenzeugenberichten verknüpfen.

Erzähler: Manchmal kann ein kleines Detail im Code eine größere Geschichte enthüllen. In der Software der Apollo-Mondlandefähre trägt eine Routine einen unerwarteten Namen: BURN_BABY_BURN. Für sich genommen ist dieser Code nur eine Bezeichnung.

Als Historiker jedoch einen der Autoren befragten, deckten sie die kulturellen Bezüge dahinter auf: es handelt sich um einen Ausdruck, der in den 1960er Jahren durch den Radio-DJ Magnificent Montague aus Los Angeles populär wurde und später mit den Watts-Unruhen von 1965 in Verbindung gebracht wurde.

Code lädt uns dazu ein, den technischen, sozialen und kulturellen Kontext seiner Entstehung zu hinterfragen. Das ist historische Forschung in der Praxis: Quellcode im Licht von Zeugenaussagen, Archivalien und weiteren historischen Belegen zu interpretieren.

Doch bevor Historiker Code untersuchen können, muss er erst einmal erhalten bleiben. Software aus den 1960er Jahren überstand Unternehmensumstrukturierungen, technologischen Wandel oder Vernachlässigung nur selten – und Quellcode war, im Gegensatz zu ausführbaren Programmen, besonders gefährdet.

Der Code der Apollo-Missionen blieb erhalten, weil Papierkopien im MIT Museum landeten und engagierte Einzelpersonen später die mühsame Arbeit der Digitalisierung und Transkription auf sich nahmen.

Von Lochkarten über Papierausdrucke, von gescannten Bildern bis hin zu Textdateien und einem Software-Repository – der Code erhielt ein neues digitales Leben.

Dieser Prozess lässt sich als ‚digitale Wiedergeburt‘ verstehen: Software, die aus erhaltenen physischen Aufzeichnungen wiederhergestellt und in digitaler Form rekonstruiert wurde.

Auf seiner Reise durchlief dieser Code drei der wichtigsten Institutionen, die sich heute der Bewahrung des Software-Erbes widmen. Das GitHub Archivprogramm  speichert Code in einem Tresorraum in der Arktis, der für eine Lebensdauer von Jahrhunderten ausgelegt ist. Über den Code hinaus macht das Internet Archive viele historische Programme durch browserbasierte Emulation zugänglich. Software Heritage, eine akademische gemeinnützige Organisation aus Frankreich, hat sich zum Ziel gesetzt, den gesamten öffentlich zugänglichen Quellcode zu bewahren.

Jede Codeebene, aus der unsere digitale Welt besteht, birgt Entscheidungen, Annahmen und Lebensgeschichten.  Code historisch lesen zu lernen bedeutet, nicht nur zu fragen, was Code tut, sondern auch, wer ihn geschrieben hat, unter welchen Bedingungen und welche weiteren Quellen erforderlich sind, um ihn vollständig zu verstehen.
